== Description ==

Prespa Wellness serves as a child theme of Prespa, inheriting all the features of Prespa. The theme is tailored for practitioners, businesses and coaches in the wellness industry, including yoga instructors, nutritionists, healthcare specialists, massage therapists and wellness coaches. The theme is optimized to work with Easy Appointments plugin, allowing users to easily book appointments and manage their schedules for free. Theme demo: https://prespa-wellness-demo.nasiothemes.com/
